# Archived Models

This directory contains superseded model packages retained for provenance,
historical reproducibility, and method review. These packages are not current
operational models and should not be selected for new analyses without an
explicit historical-comparison purpose.

| Package | Contributor | Status |
|---|---|---|
| [`risk_score_archived`](./risk_score_archived/) | Kei Hasegawa | Historical Risk Score implementation |
| [`youth_score_v1`](./youth_score_v1/) | Kaile Zhu | Deprecated early Youth Score |
| [`youth_score_v2`](./youth_score_v2/) | Zihan Zhou | Deprecated FACS Youth Score v2 |


Moving a package into `archived/` does not invalidate its historical results.
It records that the package has been superseded and is no longer the preferred
entry point.
