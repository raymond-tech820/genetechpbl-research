# Bowen Contribution Summary

I contributed the cross-module integration layer for the final manuscript.

The Methods contribution defines how Youth, Identity, Risk, and Geneformer
outputs are represented without changing their native biological methods or
merging non-equivalent score scales. It specifies the cell-versus-donor/animal
analysis units, canonical biological-unit key, exact treatment-arm handling,
pairing status, QC/provenance fields, and unknown-animal policy.

I also added two integration-level Discussion contributions. The Limitations
paragraph covers non-equivalent estimands, small animal numbers, unequal cell
counts, Risk release dependence, and the current Geneformer interface boundary.
The Future Work paragraph proposes versioned multi-dataset schemas,
cross-assay/external-validation separation, and a validated predicted-expression
adapter before Geneformer outputs can be evaluated by expression-based scorers.

There is no separate Bowen Abstract because the final paper should contain one
shared Abstract. The manuscript source is written so the Methods subsection will
appear as Section 4.1 when inserted under the paper's Methods section. The
Limitations and Future Work subsections belong in the shared Section 3 Discussion.

GitHub data and model artifacts are not duplicated in this submission package.
