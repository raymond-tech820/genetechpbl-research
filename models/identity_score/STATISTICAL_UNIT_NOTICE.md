# Statistical unit and legacy-output notice

The formal GSE176206 biological unit is:

```text
age_group x exact_treatment_arm x animal_label
```

Equal numeric animal labels from different treatment arms must not be paired.
The 2026-07-30 paired outputs, paired confidence intervals, sign-flip tests, and
figures connecting equal numeric labels across arms are superseded for formal
treatment inference.

Use the animal-level outputs generated by this code release. They preserve the
exact treatment arm and label every cross-arm comparison as unpaired.
